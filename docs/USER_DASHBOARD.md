# User Dashboard & Trading Platform

## Overview
The User Dashboard is the primary interface for retail investors on the platform. It provides a clean, intuitive, and highly responsive experience tailored for monitoring personal portfolios, executing simulated trades, and analyzing general market trends.

## Features & Use Cases Applied
- **Real-Time Portfolio Tracking:** Users can view their total balance, active investments, and 24h profit/loss.
- **Watchlists & Categories:** Stocks are grouped into sectors (Technology, Finance, etc.). Users can monitor top companies and click on external links to open Yahoo Finance directly.
- **Stock Comparison:** Users can add multiple stocks to a comparison grid, viewing real-time price deltas, charts, and key metrics side-by-side.
- **Wallet & Transactions:** Users can simulate depositing and withdrawing funds, viewing a complete transaction history (utilizing stack/queue based logging).
- **Global Search:** Fast, fuzzy-matching search bar to instantly find stocks or navigate settings.

## Enhancements
- **UI/UX:** Fully responsive design with Light/Dark mode support.
- **Shortcuts:** Added direct links to external markets (Yahoo Finance) for immediate due diligence.
- **Customization:** Users can clear recent searches and hide suggestions for a minimalist experience.
